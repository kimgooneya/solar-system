# Solar System 3D Explorer

태양과 여덟 행성을 탐색하고 유성우와 대표 혜성의 구조·특징을 함께 배울 수 있는 교육용 3D 태양계 시각화입니다.

## 주요 기능

- 태양과 여덟 행성의 인터랙티브 3D 탐색
- 주요 9개 유성우의 활동 기간, 통상 극대일, ZHR, 복사점과 모천체 조회
- 현재 날짜 기준 활동 상태와 극대일까지 남은 날짜 자동 계산
- 지구 대기권을 향하는 유성 궤적 개념 시각화
- 대표 혜성 6개의 분류, 핵 크기, 공전 주기, 근일점과 탐사 기록 비교
- 대표 혜성의 긴 타원 공전과 핵·코마·먼지 꼬리·이온 꼬리를 함께 보여주는 3D 시각화
- 선택한 혜성 하나만 모델과 궤도로 렌더링하는 단일 선택 방식
- 《마션》의 헤르메스·타이양선·MAV 구조 항로 시나리오
- 《프로젝트 헤일메리》의 지구–타우 세티·블립-A·비틀 항로 시나리오
- 영화 사건 타임라인 선택, 우주선 추적 카메라와 전체 항로 재생
- 실제 궤도 이심률과 경사도를 반영한 공전 표현
- 태양 표면 대류, 흑점, 플라스마 셸과 홍염 효과
- 행성별 정보, 지구 기준 비교, AU와 빛의 이동 시간
- 실제 지름 비율 크기 비교 모드
- 생명가능지대와 행성 분류 학습 레이어
- 행성 자동 투어와 시간 속도 조절
- 자동, 고화질, 균형, 절전 품질 프로필
- FPS 기반 적응형 렌더링과 행성 LOD
- 모바일 반응형 UI와 모션 감소 지원

## 실행

ES 모듈을 사용하므로 로컬 웹 서버에서 실행해야 합니다.

    python -m http.server 8765

브라우저에서 다음 주소를 엽니다.

    http://127.0.0.1:8765/

## 조작

- 마우스 드래그: 카메라 회전
- 휠: 확대 및 축소
- 행성 클릭: 행성 선택과 근접 이동
- 숫자키 1–9: 태양부터 해왕성까지 빠른 선택
- 상단 `유성우`: 유성우 관측소 열기 및 주요 유성우 선택
- 상단 `혜성`: 선택한 혜성의 전체 궤도 보기 및 대표 혜성 선택
- `혜성 따라가기`: 전체 궤도 화면에서 움직이는 혜성 근접 추적으로 전환
- 상단 `영화 항로`: 작품 선택, 사건별 우주선 배치와 경로 추적
- R: 전체 보기
- Esc: 정보 또는 현재 모드 닫기

## 기술

## 참고

교육적 가독성을 위해 기본 탐험 화면의 천체 크기와 거리는 실제 축척에서 조정되어 있습니다. 크기 비교 모드는 실제 지름 비율을 사용합니다.

유성우 날짜와 ZHR은 일반적인 연례 활동을 설명하기 위한 기준값이며, 정확한 극대 시각과 관측 조건은 해마다 달라집니다. 실제 관측 전에는 [IMO Meteor Shower Calendar](https://www.imo.net/resources/calendar/)를 확인하세요.

혜성의 크기와 공전 수치는 NASA·ESA 공개 자료를 학습용으로 반올림했습니다. 혜성의 핵·꼬리 크기와 궤도 거리는 한 화면에서 관찰할 수 있도록 압축한 개념 표현입니다.

영화 항로 모드는 작품에 묘사된 사건 순서와 알려진 핵심 기동을 3D로 재구성합니다. 행성 간·항성 간 거리와 사건 사이의 시간은 한 장면에서 비교할 수 있도록 크게 압축했으며, 작품에서 구체적인 궤도 수치가 제시되지 않은 구간은 시각적으로 연결했습니다.

시나리오의 과학적 맥락은 [NASA의 《마션》 궤적 분석](https://ntrs.nasa.gov/citations/20150019662), [AIP의 리치 퍼넬 기동 해설](https://www.aip.org/inside-science/inside-the-spaceflight-of-the-martian), [NASA의 《프로젝트 헤일메리》 과학 자료](https://science.nasa.gov/the-science-behind-project-hail-mary/)를 함께 참고했습니다.
